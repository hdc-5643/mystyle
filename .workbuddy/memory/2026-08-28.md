## MCP 踩坑（写新度量值）
1. 新建度量值**不能**显式设 dataType，否则报 "Cannot set the data type of a new measure explicitly"；Create 直接整体回滚。删掉 dataType 即可。
2. DAX 字符串字面量（如 `订单状态<>"退款"`）在 JSON 里双引号必须转义为 `\"`，漏转义会报 SemanticError（标记无效），并连带依赖度量值报 DependencyError。
3. Create 默认事务：单个 item 失败会整体回滚；修正后改用 Update 单条改。
