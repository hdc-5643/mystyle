## DateRangeSlicer "未激活 value 留空" 修复（11:30 已编译）
- **问题**：未激活时把 `input.value` 填成边界值（如 min），导致日历打开时已高亮该值；再点同一天 = value 不变 → `change` 不触发 → 无法激活（"选不中"）。需先点别处再退回才行。
- **方案**：未激活时 `input.value` 保持**空字符串**，边界值仅由叠加层 `.drs-value` 显示（CSS 已透明化原生文字）。激活态由 `startActive/endActive` 依 `value !== ""` 判断，不再靠"值是否等于边界"推断。
- **改动**（`src/visual.ts`）：`onChange`（删"空值自动回填边界"，仅按非空设 active）、`updateValueDisplay`（未激活显示边界值、激活显示已选值）、`update()` 初始化（value 置空+active=false）、`resetToRange()`（value 置空+active=false）、`restoreFilter()`（先全置空+未激活再按 conditions 填值）。
- **已知小限制（已向用户说明）**：value 为空时浏览器日历默认落点（min 月或 max 月）取决于浏览器版本，需导入实测确认。核心修复（点任意日期必触发激活）不受影响；不引入 focus 临时填值增强（会重现"选不中"bug）。

## DateRangeSlicer 回滚到"自动恢复边界"版（11:38 已编译）
