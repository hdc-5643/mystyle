## 页面导航器配色修正（第二轮）
- 用户反馈：页面导航器默认背景应为 HTML 顶栏色 `#0F1B30`，而非页面底色 `#0A1428`。
- 根因：第一版把 `pageNavigator` 默认填充设为 `show:false`（透明），透出页面底色 `#0A1428`；而 HTML 里 `.page-nav-item` 默认无背景、透出所在的 `.topbar`（`#0F1B30`）。
- 修正：显式把 `pageNavigator` 默认态 `fillColor` 设为 `#0F1B30`（show:true, transparency:0）。悬停 `#142436`/选中 `#1A2D44`+蓝边+左紫条/禁用 `#2C4A6B`@60% 不变。
- 区分：HTML 中 `.bookmark-item` 默认背景是 `#0A1428`（带 `#2C4A6B` 边框），故 `bookmarkNavigator` 默认保持 `#0A1428` 不变。
- JSON 结构坑：`pageNavigator["*"]` 直接是样式容器 dict，属性（`fill`/`border`/`outline`/`text`/`accentBar`）直接挂在其下，每个值是按 `$id`（default/hover/selected/disabled）分状态的数组；不要写成 `pageNavigator["*"]["*"]`。
- 页面导航器"默认灰边"根因与修法：全局 `visualStyles["*"]["*"]["border"]` 设了 `show:true`(#2C4A6B)，会渗到 pageNavigator 容器；且按钮 outline 默认是 Power BI 灰，单纯 `outline.default.show:false` 在部分版本对 default 态不生效。修法：pageNavigator `border` 显式 `show:false` 覆盖全局；`outline` default 改 `show:true` + `lineColor` 同默认填充 `#0F1B30` + `weight:1`，让描边与底色同色伪装成无边框（比纯 show:false 稳）。
- 书签导航器在 `#142436` 卡片背景下的样式：用户截图显示原深色药丸（`#0A1428` 默认）在卡片上过沉。改为"卡片内嵌幽灵风格"：默认 `#142436`(同卡片底色)+`#2C4A6B` 边框+灰字 `#B4B2A9`；悬停 `#1A2D44`+蓝边 `#378ADD`；选中 `#7F77DD` 紫底白粗字；禁用 `#2C4A6B`@60%。已写入 `主题-通用版.json` 并 0 错误校验。
