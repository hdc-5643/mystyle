### v2.4.3.0 — 补齐面板回收机制
- **根因**：视觉跑在 PBI 的 sandboxed iframe 内，点画布别处事件不跨 iframe，`document` 收不到 click → 单靠 document 监听无法「点外部收起」，**必须用 `window blur`**（v1.x 时期漏掉的解法，当时误判为无解）。
- 三条通道：document click(capture) + window blur + Esc；白名单＝触发器 + 预设按钮 + 两个日期输入框，其余一律收起（用户要求最严格判定）。
- **关键坑**：docClickHandler 在 capture 阶段，早于 trigger 的 bubble handler，所以**触发器必须在白名单**，否则「点触发器关不掉」的开关死循环。
- **保护系统日历**（用户明确要求日历逻辑不改）：blur 后 `setTimeout 0ms` 再判定，`document.hasFocus()` 为 true 或 activeElement 是日期输入框时豁免收起。
- `destroy()` 兜底解绑 blur 并 clearTimeout。

### v2.4.4.0（commit `479ab39`）—— 标头与触发器固定贴顶
- 用户反馈：视觉对象拉高后「标头 + 触发器」一行没贴顶，上方留大片空白（截图为「标头位置=左侧」）。
  并明确：**两种布局都要顶部固定**；**触发器贴顶优先、面板限高滚动**。
- **根因（flex 主轴/交叉轴在两个布局下作用相反，同一条 `flex:1 1 auto` 后果截然相反）**：
  1. **left 布局**（`flex-direction:row`，主轴水平）：`align-items:center` 作用于**交叉轴（垂直）**，
     把高度仅 30px 的 `.drs-body` 垂直居中 → 上下留白。改 `align-items: flex-start` 即可贴顶。
  2. **top 布局**（`flex-direction:column`，主轴垂直）：`.drs-body` 的 `flex:1 1 auto` 沿**主轴（垂直）**
     拉伸到视觉剩余全部高度；而 `.drs-panel` 用 `top: calc(100% + 4px)` 定位，`100%` 正是 body 高度
     → **面板被推到视觉底部之外、被 iframe `overflow:hidden` 完全裁切**（隐藏 bug，用户切到 top 布局必踩）。
     修法：`.drs-layout-top .drs-body { flex: 0 0 auto; }`。
- **⚠️ 必须用 `flex` 而非 `align-self`**：`align-self` 只作用于交叉轴，无法阻止主轴方向的拉伸。
- **不变式（后续维护必读）**：`.drs-body` 高度必须 = 触发器高度 30px；body 一旦被拉伸，
  `calc(100% + 4px)` 定位即失效、面板被裁。
- **副作用（已知且符合用户取舍）**：left 布局贴顶后 `spaceAbove` 由 `(H-30)/2-4` 变为 `-4`
  → **向上翻转不再触发**；极矮兜底阈值由 `H<238px` 变为 `H<134px`（更晚退化，限高滚动空间更大）。
- **排查结论**：`.drs-body` 构造后**无任何 JS 读取或依赖**（无 getBoundingClientRect/offsetHeight/
  getComputedStyle/ResizeObserver），`positionPanel()` 仅测 root 与 trigger → 纯 CSS 改动不影响 JS。
- **一处无效声明已标注**：`.dateRangeSlicer` 基础 `align-items` 改 flex-start **会被两个 layout class 覆盖**
  （同特异性、后声明），仅对 `applyStyles()` 执行前的窗口期生效 —— 属兜底默认值，不是修复本体。
  教训：改 CSS 前先确认该属性是否已被更具体的规则覆盖，否则写了也是死代码。
- 未改 capabilities.json，**GUID 不变**（`DateRangeSlicer20260825004`）。
- **产物校验方法修正**：pbiviz 解包后只有 `package.json` + `resources/<guid>.pbiviz.json` 两个文件，
  CSS 与 JS 都内嵌在后者里，且 **CSS 未压缩（保留换行与注释）**。用 `\.class\{...\}` 这类紧凑正则
